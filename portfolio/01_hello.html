Project Hello Quad

3D Graphics

Project Overview

This project focused on understanding the basic graphics rendering process using OpenGL. The goal was to display a textured quad on the screen by using VertexArray, Shader, Texture, and Index Buffer.

Tasks Completed

  • Organized vertex data using a VertexArray.
  • Wrote Shader code to render graphics on the screen.
  • Loaded a Texture and applied it to a quad.
  • Used an Index Buffer to reduce duplicated vertices.
  • Created my own png file and tested it as a custom texture.

Reflection

Writing the Shader code by myself took some time during this project. I learned that simply loading an image is not enough to display it on the screen. Vertex data, texture coordinates, Shader, and Index Buffer all need to be connected correctly. Through this project, I gained a better understanding of the basic OpenGL rendering process.
